# 레퍼런스 분석법 — USP 분석법 3 항목 (User's Problem · Solution · Promotion)

> 모든 경쟁사 광고를 동일한 골격으로 분해해 트렌드·패턴·빈틈을 추출하는 표준 분석법.
> `02-competitor-from-adlib` 스킬이 매 광고에 본 프레임을 강제 적용합니다.
> 본 분석법은 02 경쟁사 분석뿐 아니라 05 광고 이미지·05 영상·07 카드뉴스·08 LP 제작에도 동일하게 인용됩니다.

---

## USP 분석법 — 3 항목 + Creative Key Visual

광고 1장을 보면 다음 4축으로 분해합니다. **3항목은 메시지축, Creative Key Visual은 시각축** — 메시지와 시각을 분리해서 보는 게 핵심.

| 축 | 이름 | 추출 질문 | 어디를 보는가 |
|---|---|---|---|
| 1 | **User's Problem** | 고객의 어떤 문제를 해결하는가? (공감언어·상황) | 헤드라인 / 영상 0-3초 자막 / 모델 표정·자세 |
| 2 | **Solution** | 내 제품이 그 문제를 해결하는 이유는? (USP·차별성·근거) | 서브 카피 / 성분·임상 수치 / 권위 인용 |
| 3 | **Promotion** | 지금 구매해야 하는 이유? (프로모션·시급성) | 가격·할인 / 1+1 / 환불 보장 / 한정 |
| ★ | **Creative Key Visual** | 카테고리 노이즈를 뚫는 핵심 비주얼 1컷 | 메인 이미지·시연·라이프스타일·신뢰 자산 비주얼 |

## 항목별 추출 가이드

### 1. User's Problem (고객의 문제)

- **목적** — 0-3초 안에 "어, 내 얘기네" 시선 강탈
- **공감언어 체크**
  - 일상 불편을 정확히 짚었는가? ("거울 앞에서 안색이 왜 이래", "출근 30초 전")
  - 페르소나 상황을 구체화했는가? (직장인 / 임산부 / 야근 / 줌 회의)
  - 의문문·단정문·도발 중 어떤 톤?
- **변주 — 항상 페인일 필요 ❌**
  - **욕구형**: "광채" / "한 장으로 완성" — 페인이 아니라 *얻고 싶은 상태* 제시
  - **호기심형**: "왜 키위일까?" / "당근이 좋다는 건 아는데, 왜?" — 학습 욕구 트리거
  - **트렌드형**: "올해 K-뷰티 1순위" — 시류 편승
- **놓치면 안 될 것** — 이 한 줄이 비어 있으면 광고 효과의 70% 증발

### 2. Solution (해결책 · USP · 근거)

- **목적** — "어, 정말 해결되겠네" 신뢰 빌드
- **3 요소 (한 광고에 2~3개 동시 사용 가능)**
  - **USP 차별성** — 농도(23% 농축) / 기술(더블 레이어좀) / 자사 독자 원료(POJAE-72H)
  - **RTB 근거** — 권위(정형외과 공동 개발 / 약사 추천) / 통념("엄마가 쓰던 처방") / 숫자(임상 84% / 누적 50만)
  - **결과 시각화** — 비포애프터 / 사용 후 표정·환경 변화 / "출근부터 퇴근까지 발이 편한 하루"
- **체크포인트**
  - USP 차별성이 1개 이상 명시되는가?
  - RTB 근거가 권위·통념·숫자 중 1개 이상 있는가?
  - 결과가 시각·텍스트 둘 다로 표현되는가?

### 3. Promotion (지금 사야 하는 이유)

- **목적** — 마지막 푸시. 구매 미루기 차단
- **3 축 (한 광고에 2개 이상 결합 권장)**
  - **가격 혜택** — 20% 할인 / 1+1 / 첫 구매 X% / 듀오 세트 -25% / N% 적립
  - **리스크 제거** — 무료 교환 / 30일 환불 / 7일 체험 / 미니어처 증정
  - **시급성** — 한정 수량 / 한정 기간 / 신규 출시 / 재입고
- **체크포인트** — 두 축 이상 결합? 한 축만 있으면 약함. 시급성이 있으면 BOFU 효과 ↑

### ★ Creative Key Visual (핵심 시각 후킹)

- **목적** — 카테고리 노이즈 뚫는 시각 정체성. 3항목 메시지와 *별개로* 시각만 분석
- **체크포인트**
  - 어떤 컷이 메인? (제품 클로즈업·시연·라이프스타일·인포그래픽·신뢰 자산 배너 중)
  - 색감·질감·구도가 카테고리에서 차별화되는가?
  - 고객이 자신의 상황에 대입하기 쉬운 장면인가?
- **변주 패턴**
  - **제품 단독형**: 깨끗한 패키지 + 단색 배경 (미니멀)
  - **시연형**: 손에 든 제형 / 드로퍼 / 펴 바르는 순간
  - **라이프스타일형**: 모델이 제품 사용 후 일상 장면
  - **인포그래픽형**: 성분 분자 / 임상 차트 / Before-After
  - **신뢰 자산형**: 올리브영 1등 배지·리뷰 별점·인증 마크 (이 자체가 메인 비주얼)

## 광고 패턴 — 4 유형 (★ 모든 광고가 같은 형태 아님)

USP 3 항목은 *기본 프레임* 이지만, 실제 광고는 비중·강조 조합으로 4 유형으로 나뉩니다. **분석 시 광고를 1유형으로 분류해 라벨링**.

| 유형 | 라벨 | 어떻게 알아보나 | 예 |
|---|---|---|---|
| 1 | **default** (페인 후킹) | User's Problem 강하게 → Solution 자연 연결 → Promotion 약하게 | "거울 앞 안색이 왜 이래" → "당근 23%로 4주" → "지금 구매" |
| 2 | **trust_anchor** (신뢰 자산 강조) | User's Problem 약, Solution(권위·랭킹·인증) 강. 페인 없이 신뢰 한 방 | **"올리브영 1등 화.잘.먹 선크림"** + 별점 4.9 + OLIVE YOUNG 1+1 |
| 3 | **promotion_anchor** (할인 BOFU) | Promotion이 거의 전부. User Problem·Solution 부수적 | "듀오 세트 -25% / 한정 수량" + 가격 강조 |
| 4 | **hybrid** | 위 유형 2개 이상 동시 강조 | "임상 84% + 올영 1등 + 1+1 한정" — 신뢰 + 프로모션 동시 |

> 📝 분석 시 매 광고에 `ad_pattern` 필드로 1유형 라벨링. 통합 트렌드 추출 시 유형별 비율 집계.

## 분석 결과 기록 양식

`02_competitor/{slug}/ad-creatives/analysis.json` 의 1 항목:

```json
{
  "ad_id": "1234567890",
  "type": "image | video",
  "ad_pattern": "default | trust_anchor | promotion_anchor | hybrid",
  "analysis": {
    "users_problem": "공감언어·상황 1~2줄. 페인/욕구/호기심/트렌드 중 어떤 톤인지 명시",
    "solution": "USP 차별성 + RTB 근거(권위·통념·숫자) + 결과 시각화. 한 광고에 여러 요소면 모두 기록",
    "promotion": "가격 혜택 + 리스크 제거 + 시급성 — 실제 카피 인용",
    "creative_key_visual": "메인 비주얼 1~2줄 묘사. 5가지 변주 패턴 중 어떤 형태인지"
  }
}
```

> 트렌드 리포트에서는 `ad_pattern` 별로 그룹핑 + 항목별 패턴 가로 비교.

## 사례 1 — 베네핏 부츠 광고 (default 패턴)

| 항목 | 분석 |
|---|---|
| **ad_pattern** | `default` |
| **User's Problem** | "하루 종일 서 있어도 발이 1도 안 아파요" — 구두 신은 직장인 여성의 일상 불편을 정확히 짚는 페인 후킹 |
| **Solution** | "정형외과 공동 개발 / 누적 판매 50만 켤레 / 고객 만족도 98%" — 권위 + 숫자 + 사회적 증거 3요소 결합. "출근부터 퇴근까지 발이 편한 하루" 결과 시각화 |
| **Promotion** | "지금 첫 구매 시 20% 할인 + 무료 교환" — 가격 혜택 + 리스크 제거 결합 |
| **Creative Key Visual** | 출근길 지하철에서 구두를 신고 편하게 걷는 여성 다리. 구두에 빛 물리는 연출로 시선 유도. 라이프스타일형 |

## 사례 2 — 굿달 화.잘.먹 선크림 (trust_anchor 패턴)

| 항목 | 분석 |
|---|---|
| **ad_pattern** | `trust_anchor` |
| **User's Problem** | 약 — 페인 카피 없음. "민감 피부도 편하게" 라는 욕구형이 살짝 |
| **Solution** | "**올리브영 1등** + 별점 4.9 + 무기자차 + 산뜻촉촉" — 랭킹(권위) + 숫자(별점) 메인 |
| **Promotion** | "OLIVE YOUNG 1+1 특가 확인하기" — 1+1 + 채널 한정 시급성 |
| **Creative Key Visual** | 푸른 하늘 배경 + 제품 2개 1+1 강조 + 별점 카드 + 산뜻촉촉 카드 — 신뢰 자산형 |

> 본 사례는 페인 후킹 없이 **신뢰 자산(랭킹·별점) 단독으로 1·2단 후킹·약속을 대체**한 변주.

## 통합 트렌드 추출 시 적용

여러 광고를 3항목 + Creative Key Visual + ad_pattern 으로 분해한 뒤, **항목·패턴별 가로 비교**:

- **ad_pattern 분포** — 경쟁사가 default 광고가 70% 이면 우리는 trust_anchor 로 빈틈 노림 가능
- **User's Problem 톤** — 페인 vs 욕구 vs 호기심 vs 트렌드 비율
- **Solution USP 키워드 Top 10** — 어떤 차별성을 강조하는가
- **Solution RTB 유형 분포** — 권위·통념·숫자 비율
- **Promotion 축 결합** — 가격 단독 vs 가격+리스크 vs 가격+시급성 vs 3축
- **Creative Key Visual 변주 분포** — 제품 단독·시연·라이프스타일·인포그래픽·신뢰 자산 비율

이 가로 비교가 `competitor_ads.md` 의 트렌드 매트릭스 + 자사 빈틈 도출의 기반입니다.
